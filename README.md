> **Evaluación práctica e interactiva** sobre persistencia, indexación y validación de consistencia en estructuras de datos dinámicas para catálogos bibliotecarios y control de colecciones.

---

## 🎯 Objetivos de la Evaluación

* Demostrar la implementación limpia de estructuras dinámicas de datos sin fuga de memoria.
* Validación estricta de invariantes de datos (claves únicas, ordenamiento estable, integridad referencial).
* Desacoplamiento de componentes de interfaz y capas lógicas de dominio.
